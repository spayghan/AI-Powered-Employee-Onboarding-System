# 🚀 AI-Powered Employee Onboarding Automation System

An **AI-powered, no-code Employee Onboarding System** designed to simplify and automate the complete employee onboarding process.

The system allows HR to register new employees, collect required documents, verify submitted information, track onboarding progress, approve onboarding, and automatically send onboarding emails.

## 📌 Project Overview

Employee onboarding is often a time-consuming process involving multiple forms, documents, verification steps, HR approvals, and communication.

Our system brings these processes together into a single automated workflow.

### Main Workflow

```text
HR Adds Employee
       ↓
Employee Receives Welcome Email
       ↓
Employee Uploads Required Documents
       ↓
Document Information is Extracted using OCR
       ↓
HR Reviews Documents
       ↓
Documents are Verified
       ↓
HR Approves Onboarding
       ↓
Onboarding Progress is Updated
       ↓
Employee Receives Confirmation Email

```
